## 测试方式和状态处理

使用后台固定实例测试接口 `POST /api/v1/admin/accounts/{id}/test`，模型为 `deepseek-v4.1-flash-free`，提示词为 `What is 2 + 3? Reply with only the number 5.`。这些实例均显式使用 OpenCode free Bun 接入，后台在 adaptive 多协议测试之前进入该分支：固定账号与其绑定代理，单次 worker 派发，没有账号切换或重试。

成功需同时满足完整后台 SSE 无 error、唯一 test_start 且模型正确、唯一 test_complete.success=true，以及回复恰为 5。后台在报告成功前，还会校验上游 HTTP 200、完整 SSE、合法 usage、free billing source、结束标记等。后台测试响应本身的 HTTP 200 不代表模型调用成功，表中 200/429 是上游结果。

本次九个 429 命中了本地免费额度错误分类并重新设置冷却；没有清除这些新冷却或补测。这一分类与冷却记录本身不能独立证明上游真实免费额度已耗尽。测试完成时记录的冷却截止时间：
